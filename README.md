# Kiosk Satellite – Casting Helper


- Your kiosk becomes discoverable as a casting destination.
- Open up new possibilities for remote media playback.
- Use your existing network to find available devices.
- Turn your kiosk into a convenient cast endpoint.
- Unlock seamless device discovery across your network.
- Bring casting capabilities to your kiosk setup.
- Enjoy a simpler way to connect and cast.
- ^



## Installation:
On each Kiosk Satellite:
- download the .zip [Casting Helper 0.3.3](https://gitlab.tiered.top/api/v4/projects/3/packages/generic/casting-helper/latest/casting-helper.zip)
- open settings > plugin manager
- add plugin via .zip
- select .zip file you downloaded
- turn on switch
- if display is not a cast option, reboot display once.
